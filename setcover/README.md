# Задача о покрытии множествами

## Запуск
```bash
./run.sh
```

Скрипт собирает `main.cpp` и запускает чекер на шести тестах. Чекер проверяет, что все элементы покрыты, и пересчитывает стоимость выбранных множеств

## 1. Жадник

Сначала я написал жадный алгоритм. На каждом шаге для каждого множества считается отношение его стоимости к числу новых элементов, которые оно покрывает. Выбирается множество с минимальным отношением, после чего процесс повторяется, пока не будут покрыты все элементы

| Тест | Стоимость | Скор |
|---|---:|---:|
| `sc_157_0` | 102100 | 3 |
| `sc_330_0` | 30 | 0 |
| `sc_1000_11` | 170 | 3 |
| `sc_5000_1` | 36 | 3 |
| `sc_10000_5` | 76 | 3 |
| `sc_10000_2` | 192 | 3 |

Проблема жадника понятна, множество, выгодное в начале, позже может стать ненужным

## 2. Удаление избыточных множеств

После построения жадного решения я посчитал, сколько выбранных множеств покрывает каждый элемент. Затем выбранные множества просматриваются от дорогих к дешевым. Множество удаляется, если после этого каждый его элемент все еще покрыт хотя бы один раз

| Тест | Стоимость | Скор |
|---|---:|---:|
| `sc_157_0` | 102100 | 3 |
| `sc_330_0` | 30 | 0 |
| `sc_1000_11` | 156 | 3 |
| `sc_5000_1` | 32 | 3 |
| `sc_10000_5` | 69 | 3 |
| `sc_10000_2` | 181 | 3 |

Стоимость уменьшилась на четырех тестах

## 3. Локальный поиск

Дальше я добавил локальный поиск с обменом двух выбранных множеств на одно невыбранное. Для пары множеств находятся элементы, которые перестанут быть покрыты после их удаления. Если существует более дешевое множество, покрывающее все эти элементы, обмен принимается. Обмены повторяются, пока удается уменьшать целевую функцию

| Тест | Стоимость | Скор |
|---|---:|---:|
| `sc_157_0` | 96900 | 3 |
| `sc_330_0` | 29 | 3 |
| `sc_1000_11` | 151 | 3 |
| `sc_5000_1` | 32 | 3 |
| `sc_10000_5` | 69 | 3 |
| `sc_10000_2` | 177 | 3 |

## 4. GRASP

Далее я добавил GRASP. Алгоритм случайно выбирает одно из множеств с близким отношением стоимости к числу новых покрываемых элементов. Так строятся разные начальные решения

К каждому построенному решению применяется удаление избыточных множеств и локальный поиск. Из всех результатов сохраняется решение с минимальной стоимостью

| Тест | Стоимость | Скор |
|---|---:|---:|
| `sc_157_0` | 94600 | 3 |
| `sc_330_0` | 23 | 5 |
| `sc_1000_11` | 147 | 5 |
| `sc_5000_1` | 30 | 5 |
| `sc_10000_5` | 64 | 5 |
| `sc_10000_2` | 169 | 3 |
